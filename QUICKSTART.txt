=====================================
📊 СОБИРАЕМЫЕ МЕТРИКИ:
=====================================

HTTP:
  • http_requests_total{method,route,status}
  • http_request_duration_seconds{...} (P50, P95, P99)

Devices:
  • active_devices
  • device_commands_success_total
  • device_commands_failed_total

Price:
  • electricity_price_eur (текущая цена)
  • price_updates_total{status}

System:
  • active_users
  • errors_total{error_type}
  • savings_eur

=====================================
📝 ЛОГИРОВАНИЕ:
=====================================

Уровни: INFO, WARN, ERROR, CRITICAL

Пример:
  lokiLogger.info('device_created', { deviceId: 1, name: 'Boiler' })
  lokiLogger.error('price_fetch_error', { error: 'Timeout' })

Логи отправляются в Loki через Docker logging driver
Также видны в: docker logs power-bot
